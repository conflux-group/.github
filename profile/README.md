# Conflux Group

---

## 关于我们

**Conflux Group** 是由多个联飞平台的开发者、管制员与维护者共同发起的协作组织。

我们专注于：

- **合作扇区**：共同制作、合并与维护空管扇区文件及相关配置。
- **地图统一**：打通不同平台的在线信息，构建统一、可扩展的连飞地图。
- **开放分发**：通过 GitHub 组织与下载页发布扇区 / 地图资源，降低使用门槛，方便各平台跳转与协作。

**Conflux** 意为“汇流”，象征不同平台、扇区与数据最终汇聚到一起。

> 主要合作平台：APOC、XFS 等（持续扩展中）。

## 项目方向

| 方向 | 说明 |
| --- | --- |
| **扇区制作** | `sct` / `ese`、地面扇渲染、TopSky、Ground Radar、MTEP、RDF 等配置 |
| **地图统一** | 多平台在线信息接入，WebSocket / SSE / FSD 推送，航路 / 气象 / 飞机图片 | 
| **数据整理** | EAIP等数据源转换，兼容常见模拟机导航数据 | 
| **下载与文档** | GitHub 组织主页、下载页、文档站、平台跳转 | 

> 具体仓库请查看 [Repositories](https://github.com/orgs/conflux-group/repositories)。

## 参与方式

1. 阅读各仓库的 `README` 与 `CONTRIBUTING.md`。
2. 在 Issue / Discussions 中认领任务或提出建议。
3. Fork → 新建分支 → 提交 Pull Request。
4. 至少一位维护者评审通过后合并。

欢迎开发者、管制员、地图维护者、文档与设计贡献者加入。
